As palavras em ingles

Toda palavra em ingles que aparece neste sistema esta nesta lista, com o que ela faz e onde ela aparece. Elas sao do JavaScript, do SQL e do HTML, e nao da para traduzir: sao os nomes de verdade, os mesmos que voce vai encontrar em qualquer tutorial.

No banco de dados (SQL)

palavrao que fazno nosso codigo
CREATE TABLE cria uma tabela CREATE TABLE IF NOT EXISTS turma (...)
o IF NOT EXISTS quer dizer "se ela ainda nao existir". Sem ele, rodar o programa duas vezes daria erro.
SELECT me mostre SELECT * FROM turma
o * quer dizer "todas as colunas"
INSERT INTO guarde um novo INSERT INTO turma (nome) VALUES (?)
UPDATE e SET troque os dados UPDATE turma SET nome = ? WHERE id = ?
DELETE FROM apague DELETE FROM turma WHERE id = ?
WHERE so nas linhas em que... A palavra mais perigosa do SQL. Esquecer o WHERE num DELETE nao da erro: funciona, e apaga a tabela inteira.
ORDER BY ordene por ORDER BY nome   (de A a Z)
JOIN e ON junte outra tabela, casando por... INNER JOIN turma ON turma.id = aluno.turma_id
e assim que o nome da turma chega na tela de alunos. Esta na rota 5.
INNER e LEFT o tipo de juncao INNER traz a linha so se o par existir nos dois lados. LEFT traz sempre, e vem vazio quando nao ha par. A rota 9 usa LEFT para a oficina sem inscritos aparecer com zero.
AS apelido para a coluna turma.nome AS turma_nome
obrigatorio quando duas tabelas tem colunas com o mesmo nome, e as duas se chamam "nome"
COUNT conte quantas linhas COUNT(inscricao.id) AS inscritos
GROUP BY junte as linhas em grupos com GROUP BY oficina.id, o COUNT conta uma vez por oficina, em vez de contar a tabela toda
PRIMARY KEY esta coluna identifica a linha e sempre o id aqui
AUTOINCREMENT preencha sozinho, somando 1 voce nunca escreve o id: o banco escreve
FOREIGN KEY e REFERENCES esta coluna aponta para outra tabela FOREIGN KEY (turma_id) REFERENCES turma(id)
depois desta linha, o banco recusa excluir uma turma que tem alunos
NOT NULL nao pode ficar vazio use so no que realmente impede o registro de existir
UNIQUE este valor nao pode repetir UNIQUE (aluno_id, oficina_id)
com dois campos juntos, e a COMBINACAO que nao pode repetir: o mesmo aluno nao entra duas vezes na mesma oficina
NULL vazio, "nao sei" diferente de zero e diferente de texto vazio. A nota de quem se inscreveu e ainda nao foi avaliado e NULL.
PRAGMA um ajuste do SQLite PRAGMA foreign_keys = ON
liga a protecao das chaves estrangeiras, que vem desligada. Sem esta linha, as FOREIGN KEY nao protegem nada.

No servidor (Node)

palavrao que fazno nosso codigo
require traga uma ferramenta de outro arquivo var banco = require('./banco');
o ./ quer dizer "o arquivo desta pasta"
module.exports entregue isto para quem der require a ultima linha do banco.js. Sem ela, o servidor receberia um objeto vazio.
createServer crie o servidor a funcao que vai dentro dele roda UMA VEZ POR PEDIDO que chega
listen fique escutando nesta porta servidor.listen(3000)
e por isso que o endereco termina com :3000
run, get, all os tres jeitos de falar com o banco run para mudar algo (INSERT, UPDATE, DELETE). get para pegar UMA linha. all para pegar VARIAS.
this.lastID o id que o banco acabou de criar so funciona dentro de function (erro) {}. Com a seta (erro) => {} ele vem vazio, e nenhum erro aparece.
this.changes quantas linhas mudaram zero quer dizer que aquele id nao existe. Sem testar isso, alterar o registro 999 responderia "alterado com sucesso".
serialize um comando depois do outro, na ordem sem ele, os comandos do banco.js sairiam todos ao mesmo tempo, e o INSERT poderia chegar antes do CREATE TABLE
JSON.parse texto que vira objeto o que chegou pela rede e texto; o parse transforma em algo que o programa consegue ler
JSON.stringify objeto que vira texto o contrario, para poder viajar pela rede

Na tela (JavaScript do navegador)

palavrao que fazno nosso codigo
document a pagina inteira o nome tecnico dessa representacao da pagina e DOM
getElementById ache o pedaco da pagina com este id document.getElementById('campoNome')
se o id estiver escrito diferente no HTML, voce recebe o erro "Cannot read properties of null"
createElement crie um pedaco novo de pagina document.createElement('tr')
ele ainda nao esta na pagina: so existe
appendChild pendure dentro de AGORA ele entra na pagina. Criar e pendurar sao duas coisas.
textContent o texto de dentro, como texto puro use SEMPRE este com texto que alguem digitou
innerHTML o conteudo de dentro, tratado como CODIGO HTML so usamos para LIMPAR (innerHTML = ''). Com texto de pessoa, um nome com <script> dentro seria executado. Nome do ataque: XSS.
addEventListener escute isto, e quando acontecer faca aquilo botao.addEventListener('click', ...)
os que usamos: click, submit (enviar formulario) e DOMContentLoaded (a pagina carregou)
preventDefault nao faca o que voce normalmente faria obrigatorio no submit. Sem ele, o navegador recarrega a pagina inteira e nada e salvo. E o defeito numero 1 de quem comeca: a tela pisca e nada acontece.
fetch va buscar isto no servidor nao devolve a resposta na hora: devolve uma promessa de resposta
then quando chegar, faca isto porque a rede demora. Se o navegador ficasse parado esperando, a pagina travaria.
catch se nem der para falar, faca isto diferente de uma resposta negativa: aqui o servidor nao respondeu nada
Promise.all espere varios terminarem no inscricoes.js, para os dois selects. Os pedidos saem ao mesmo tempo, em vez de um depois do outro.
forEach para cada item da lista, faca isto com 3 turmas, o pedaco de dentro roda 3 vezes
value o que esta escrito no campo e sempre TEXTO, mesmo num campo de numero
hidden esconda este elemento usamos no botao cancelar, que so aparece durante uma edicao
disabled trave este campo na tela de inscricoes, ao mudar a nota: os dois selects travam, porque a rota 15 muda so a nota
confirm mostre uma pergunta de sim ou nao antes de excluir, sempre
console.log escreva isto no painel do F12 a ferramenta mais util quando algo nao funciona: imprima o que voce acha que sabe

No HTML

palavrao que fazno nosso codigo
id apelido unico na pagina e como o JavaScript acha aquele elemento. Nao pode repetir na mesma pagina.
class etiqueta que varios elementos podem ter e por ela que o CSS pinta. Um elemento pode ter varias, separadas por espaco.
type="hidden" um campo que nao aparece na tela e ele que decide se o botao Salvar vai cadastrar ou alterar
type="button" um botao que so clica obrigatorio em botao dentro de formulario que NAO e para enviar. Sem isso, o botao cancelar salvaria.
select e option uma lista de escolha cada option carrega duas coisas: o value (o numero, que vai para o banco) e o texto (o nome, que a pessoa le)

Os numeros que o servidor responde

numeroquer dizerquando
200deu certoaqui esta o que voce pediu
201criadogravei, e o id e tal
400voce pediu erradofaltou campo, ou o banco recusou
404nao existeesse id nao esta aqui
500EU erreidefeito no servidor. Va olhar o terminal.
A diferenca entre 400 e 500 e a mais importante: 400 quer dizer "o problema e no seu pedido"; 500 quer dizer "o problema e meu". Quando voce ver 500, pare de mexer na tela e va olhar o terminal onde o servidor esta rodando.
